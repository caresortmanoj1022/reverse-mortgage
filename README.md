# Spectrum One Reverse mobile demo

A Flutter Android demo of a reverse mortgage estimate flow, inspired by the JERRY™ calculator at Spectrum One Reverse. It is a click-through visual mockup with fixed sample results; form values do not change the displayed estimate.

The Spectrum One Reverse logo and Jerry images are sourced from [spectrumonereverse.com](https://spectrumonereverse.com/). This is an independent UI demo and is not affiliated with or endorsed by Spectrum One Reverse.

## Run

Install Flutter, then run `flutter create . --platforms android`, `flutter pub get`, and `flutter run` from this directory. The Android runner is generated by Flutter for your installed SDK version.

The GitHub Actions workflow at `.github/workflows/build-android-apk.yml` builds a release APK on pushes to `main`/`master` or when manually started. It uploads `spectrum-reverse-demo-apk` as a downloadable workflow artifact.

The displayed figures are sample content only. The app is not connected to lender pricing, rates, fees, or underwriting.
